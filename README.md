# OTBridge — development moved

OTBridge now lives in the public [NekokoLPA2 repository](https://github.com/iebb/NekokoLPA2/tree/master/otbridge).

- [Current source and build instructions](https://github.com/iebb/NekokoLPA2/tree/master/otbridge)
- [Current APK and Magisk/KernelSU module releases](https://github.com/iebb/NekokoLPA2/releases)
- [OTBridge versus the full rooted app](https://github.com/iebb/NekokoLPA2/blob/master/docs/android-root.md)

This repository retains the historical source, MIT license and existing releases. Its legacy build workflow is manual-only and uploads inspection artifacts; current release publishing happens in NekokoLPA2. The helper's package `ee.nekoko.nbridge` and provider authority `ee.nekoko.nbridge.provider` are retained.
